profile — a person, not a record

Every other Wavee page is about a record (an album, a playlist, an artist's catalogue). A profile is about a person, so it borrows the Zune social voice: the person's own colour fills the room, their name is set as panorama typography, counts are numerals rather than labels, and the social lists lead with faces. Everything is built from parts Wavee already has — the artist-hero veil, the shared media surface, the pivot label, the tick header, the capsule CTA, FlipDigit — and stays inside the engine's type policy. Data per profile-pages-api-research.md: one user-profile-view/v3 read paints the whole header and overview; the two lists are unpaged; top artists are own-profile only.

their colourThe hero veil is colorRaw of the avatar (fetchExtractedColors), or the brand avatar colour from the profile itself when there is no picture — never a generic accent.
panorama nameThe name in the display face, and its ghost — the same word, huge and faint, running off the right edge the way Zune's panorama titles did. Door's ghost-numeral idiom, one decorative rung.
numerals, not labelsfollowers · following · public playlists as 40/52 display numerals with lowercase captions. Each one is a doorway into its pivot; a follow rolls the count with FlipDigit.
faces firstFollowers and following preview as a face mosaic with the exact count; the full list gets artists/people chips, find-in-list and a Zune jump list — it is one unpaged response.

**The decoder is the point.** Identity is a packed `EntityId` now: the wire's 16-byte gid goes straight to a slot
through `Table.Slot(EntityKind, ReadOnlySpan<byte> gid16)` (3 ns) and never becomes a string. Text goes into the
staging arena as UTF-8 and is interned on the UI drain — the socket thread must not touch the `StringTable` (C1).
Every `StringId` a column owns is ref-counted: write with `t.SetText(ref t.Title, slot, id)`, never
`t.Title[slot] = id`, and implement `ReleaseText(slot)` on every table (see the pattern in `Entities.cs`'s `Table`
header — doing the release half without the write half is worse than doing neither).

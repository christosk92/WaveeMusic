## Rules

- **Model split:** Opus for intricate code (decoders, reducers, hot-path CORE), Sonnet for mechanical ports, skeletons
  and doc edits; Fable orchestrates and verifies.
- **Minimal gates:** the orchestrator runs ONE Debug build, ONE Release build and ONE test run per wave. No VerticalSlice
  unless the engine changed. **Subagents never build, test, or touch git.**
- **The data layer's rules:** identity is `EntityId`; the wire's 16-byte gid reaches a slot through
  `Table.Slot(EntityKind, ReadOnlySpan<byte> gid16)` and never becomes a string. Every `StringId` column write is
  `t.SetText(ref t.Column, slot, id)`, never `t.Column[slot] = id`, and every table implements `ReleaseText(slot)` —
  the release half without the write half is worse than neither. The socket thread never touches the `StringTable`;
  text goes to the staging arena as UTF-8 and is interned on the UI drain (C1).
- **P1–P16 / C1–C10** (`C:\Users\ChristosKarapasias\Documents\relationships_wavee.md` §5.11/§5.12) bind every CORE
  file. **SIMD only above ~16 elements** — measured on this machine, scalar wins below that.
- CLAUDE.md's out-of-scope paths are off limits. Do not create the PlayPlay junction in this worktree until Wave 2
  re-homes the audio stack that binds it.
- Every fix references a GitHub issue; the CHANGELOG bullet carries `(#n)`. Every modifying `gh` call needs Christos's
  approval.

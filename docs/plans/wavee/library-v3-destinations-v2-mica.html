Library V3 destinations — take 2

Reaching Liked Songs, Albums, Artists, Podcasts and Local files from the Library V3 pane (issue #85 H4). Counts are already warm (LibraryStats); routes already registered (ShellRoutes). The question is purely what it should look like.

✗ What shipped and was rejected: seeding the shared top bar so the band renders five ordinary full-width rows above "Your Library". It reads as Classic bolted onto V3, spends ~200 DIP above the fold, and pushes the actual library below it. None of the four below do that.

Recommendation: A, with B's picker as the narrow-pane fallback. A keeps all five visible for one row of height and cannot be mistaken for library content — which was the whole failure of the shipped version. Below the width where five labelled tiles fit, the strip collapses into the header caret from B rather than wrapping into a second row.

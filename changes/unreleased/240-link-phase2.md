**Rename your files, keep several versions of one song, and choose which one plays.** "Rename…" in a file's menu
(on its row, or on its row under Track details' Versions and formats) lets you call "Savin' Me" "Savin' Me (hardstyle remix)". The
new name shows only in Wavee on this PC: the file keeps its own tags, and Undo puts the old name back. Link a second
file to a Spotify song and it becomes another version of that song. "Play by default" on the song's menu, or under its
versions, picks which one plays everywhere that song shows up on this PC, playlists you follow included. The song's
Versions list marks that one "Plays by default", and its file mark says which file plays. Pick "Spotify's version" to
switch it back. In Settings > Playback, "Prefer my files when I have them" (off by default) plays your file for every
linked song where you haven't picked. Your devices and Spotify are told what really played: a file plays as your file,
not as the Spotify song. A file you add to a Spotify playlist goes in as its own local-file row, so a playlist can hold
"Savin' Me" and your remix side by side. (#240)

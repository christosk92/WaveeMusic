**Choose a colour set for light mode and another for dark.** Settings › Appearance › Colours offers a colour set for each mode,
and App mode switches between them, following Windows when it is on System: Catppuccin Latte, Frappé, Macchiato and
Mocha, Nord Snow Storm and Polar Night, Gruvbox Light and Dark, Dracula, and Wavee's own Paper and Ink (a true-black OLED
set with a saturated blue). The accent can come from your colours (Catppuccin's fourteen accents, Nord's Frost and
Aurora, and so on) or stay your theme's. Every set works in Classic, WinUI and Zune; text colours are adjusted where
needed so they stay readable, and a mode with a colour set draws on a solid window instead of Mica. While a set is on,
album art no longer tints the window or leads a page's accent, so the colours stay exact; Artwork colours brings that back
(the full-screen player and the lyrics keep the cover's colours either way).

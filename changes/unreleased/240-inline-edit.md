**Renaming a playlist works the same way in WinUI and Classic, and the text no longer moves.** Hover the name or
description to see a plate and a pencil, then click it (or press Enter or F2) to edit. The text stays where it was,
fully selected and wrapped on the same words. Save and Cancel appear under it. An empty name keeps Save off and says
why, and "Saving…" and "Saved" show at the end of the line without pushing the page down. A version card's title in
Track details renames the same way, in every theme.

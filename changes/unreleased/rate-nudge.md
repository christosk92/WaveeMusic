**Wavee asks, rarely, for a rating or a star.** A Microsoft Store install is asked for a Store rating and a GitHub
install for a star on GitHub, in a small card above the player bar at a quiet track change: if you already used Wavee,
once on this update, then at 25 and 100 hours of listening, never more than three times, and never while you type,
watch video, use full screen or the visualizer, or while Wavee is in the tray. Not now, Don't ask again, or ignoring it
are all fine, and Settings → About has an on/off switch. The same rating or star link sits in Settings → About, the
account menu and the after-update summary, in Classic, WinUI and Zune.

**Dropping a video on a song in Local files no longer says "That file couldn't be found."** A song row on Local files (On
this PC) is a file of its own, so it no longer offers to link the dropped .mp4 as its video: the drop goes to the page
instead, which adds the video to your library and plays it, as a drop anywhere else does. Linking a video to a Spotify
song is unchanged, and when a link is refused the message now says why (not an .mp4, the file is gone, or Wavee couldn't
add it to your library) instead of always saying the file couldn't be found. The row menu's Video ▸ verbs are no longer
offered on a local file either. All themes.

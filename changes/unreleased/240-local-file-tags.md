**A dropped or opened local file shows its own title, artist, album and length.** Wavee now reads the tags of MP3
(ID3v2.2 to 2.4, ID3v1 and APE), FLAC, Ogg Vorbis, M4A and AAC files, so a file dropped on the window or opened with
Play ▸ File… appears in Local files under its real name with its artist, album and duration, instead of its file name
and no length; a file without tags keeps its file name as before. .m4a and .aac files can now be dropped and picked
too. A local file Wavee names to your other devices is spelled the way the Spotify app spells it (a title with `~` or
`*` in it no longer differs). In Classic, WinUI and Zune. (#240, the first part of local files.)
